# 📚 40-Day Tech Learning Planner

A mobile-friendly personal learning planner designed to help track and complete a structured **40-day technical roadmap**.

The planner covers **AI/ML, DSA with Java, Full Stack Development, and Solidity/Web3**, with detailed daily subtopics and progress tracking.

## 🚀 Features

- 📅 40-day structured learning plan
- 🤖 AI/ML roadmap
- 💻 DSA & Java roadmap
- 🌐 Full Stack Development roadmap
- ⛓️ Solidity & Web3 roadmap
- ✅ Individual subtopic checkboxes
- 📊 Overall progress tracking
- 💾 Progress saved automatically using LocalStorage
- 📱 Mobile-friendly responsive design
- ▶️ YouTube learning resources
- 🔄 Reset progress option
- 🎯 Complete-day functionality

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
- YouTube Resources
